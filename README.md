An end-to-end retail analytics project that turns raw customer shopping data into business insight. The pipeline cleans and models transaction-level data in **Python**, analyzes customer segments, loyalty, and purchase drivers in **PostgreSQL/SQL**, and surfaces the resulting trends in an interactive **Power BI** dashboard — enabling data-driven decisions around customer engagement, retention, and marketing strategy.

## Overview

- **Dataset:** 3,900 retail transactions across 18 features (demographics, purchase details, shopping behavior).
- **Pipeline:** CSV → Python (cleaning & feature engineering) → PostgreSQL → SQL analysis → Power BI dashboard.
- **Business goal:** identify what drives repeat purchases and customer loyalty, and recommend where to focus marketing and retention efforts.

## Key Business Questions Answered

The SQL analysis (`sql/customer_behavior_sql_queries.sql`) answers 10 business questions, including:

1. Revenue generated by male vs. female customers
2. High-spending customers who still use discounts
3. Top 5 products by average review rating
4. Purchase amount comparison: Standard vs. Express shipping
5. Spend comparison: subscribers vs. non-subscribers
6. Products most dependent on discounts
7. Customer segmentation: New, Returning, and Loyal
8. Top 3 products purchased within each category
9. Whether repeat buyers are more likely to subscribe
10. Revenue contribution by age group

## Setup & Reproduction

### 1. Clone the repository and install dependencies

```bash
git clone https://github.com/arfa3904/customer-behaviour-analysis.git
cd customer-behaviour-analysis
pip install -r requirements.txt
```

### 2. Configure your database credentials

This project connects to a local **PostgreSQL** database. Copy the example env file and fill in your own values:

```bash
cp .env.example .env
```

Edit `.env`:

```
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=customer_behavior
```

`.env` is git-ignored — never commit real credentials.

### 3. Create the database

In PostgreSQL (e.g. via pgAdmin or `psql`), create a database matching `DB_NAME`:

```sql
CREATE DATABASE customer_behavior;
```

### 4. Run the notebook

Open `notebooks/customer_shopping_behavior_analysis.ipynb` and run all cells. It cleans the raw CSV, engineers features (`age_group`, `purchase_frequency_days`), and loads the result into a `customer` table in your PostgreSQL database.

### 5. Run the SQL analysis

Run the queries in `sql/customer_behavior_sql_queries.sql` against the `customer` table to reproduce the segment, loyalty, and revenue insights.

### 6. Explore the dashboard

Open `dashboard/customer_behavior_dashboard.pbix` in Power BI Desktop to view the interactive dashboard.

## Business Recommendations

- **Boost subscriptions** — promote exclusive benefits for subscribers.
- **Customer loyalty programs** — reward repeat buyers to move them into the "Loyal" segment.
- **Review discount policy** — balance sales boosts against margin control.
- **Product positioning** — highlight top-rated and best-selling products in campaigns.
- **Targeted marketing** — focus on high-revenue age groups and express-shipping users.

## Notes

- The notebook's "Alternative Connection Examples" section shows how the same load pattern could be adapted for MySQL or SQL Server; those cells are reference-only and are not used in this project.
- `age_group` is derived from fixed business-defined bins: 18–25 (Young Adult), 26–40 (Adult), 41–55 (Middle-aged), 56–70 (Senior).
